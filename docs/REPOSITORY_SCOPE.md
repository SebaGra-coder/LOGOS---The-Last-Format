# Ambito della repository

Questa repository pubblica è destinata alla **documentazione e alla presentazione del progetto LOGOS – The Last Format**, non alla distribuzione della build Windows o del progetto Unity completo.

## Cosa è incluso

- README e documentazione descrittiva del progetto.
- Galleria di immagini in [`docs/images/`](images/), con render dei personaggi, panoramiche dei tre livelli e dell'arena finale, e tre screenshot catturati durante la demo.
- File di configurazione Unity già presenti nel repository.
- Configurazione dei pacchetti e versione dell'editor, utili a identificare l'ambiente di sviluppo.

I materiali visivi hanno provenienze differenti: i render mostrano i modelli dei personaggi, le panoramiche documentano il level design e tre screenshot mostrano momenti della demo in esecuzione (distruzione del mondo, camminata e combattimento).

## Cosa non è incluso

- Codice sorgente completo dei sistemi gameplay.
- Asset 3D e audio originali del gioco.
- Build eseguibile Windows.
- Filmato gameplay, che viene mantenuto privato.

La struttura Unity attualmente presente contiene file di configurazione, una scena di esempio e materiale tutorial del template URP; **non rappresenta il progetto di gioco completo né dimostra da sola l'implementazione dei sistemi descritti nella documentazione**.

## Stato

LOGOS ha raggiunto una demo giocabile sviluppata individualmente in circa cinque mesi. Il progetto non è attualmente in sviluppo attivo. La documentazione distingue le funzionalità presenti nella demo dagli elementi parziali o non implementati.

## Risorse di terze parti

Il progetto utilizza risorse di animazione Mixamo, animazioni disponibili in Unity e alcune risorse audio esterne. La pubblicazione o redistribuzione di tali materiali richiede il rispetto delle rispettive licenze e condizioni d'uso.
